# The Dog Ate My Homework: Funniest Excuse

One line (125 characters) — the excuse a dog gives after being caught eating the homework.

> The worksheet said 'do not fold, spindle or mutilate' — so I ate it whole. Technically I followed the instructions perfectly.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
